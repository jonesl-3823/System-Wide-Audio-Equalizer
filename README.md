## Overview

**Equalizer APO** — A powerful parametric equalizer for Windows audio. It runs on **Windows** and is distributed under the **LGPL-3.0** license.

If you searched for *"equalizer apo download"*, this is the tool you are looking for. Below you will find a feature breakdown, platform-by-platform installation instructions, a quick-start example, and answers to the most common questions.

## Key Features

- Unlimited filters with low latency
- Works on any output device
- Pairs with Peace GUI
- Convolution and VST support
- Per-app configuration
- Open source
